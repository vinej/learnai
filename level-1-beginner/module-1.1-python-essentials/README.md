# Module 1.1 — Python Essentials

**Level:** 1 — Beginner
**Estimated time:** 2 weeks

## Goal
Get fluent with core Python so you can read, write, and debug small programs without friction.

## Topics
- Variables, primitive types, operators
- Control flow: `if`, `for`, `while`, `match`
- Functions, scope, lambdas, default args, `*args`/`**kwargs`
- Comprehensions (list, dict, set, generator)
- Built-in data structures: `list`, `dict`, `set`, `tuple`, `frozenset`
- Strings, f-strings, common string methods
- File I/O with `open`, `with`, and `pathlib`
- Exceptions: `try`/`except`/`finally`, raising, custom exception classes
- Modules, packages, the `import` system
- Virtual environments: `venv`, `pip`, `pyproject.toml`

## Exercises
1. Build a CLI todo list that persists state to a JSON file.
2. Implement FizzBuzz, then refactor it using comprehensions.
3. Word-frequency counter from a text file (handle punctuation & case).
4. A calculator that handles invalid input via custom exceptions.
5. Reorganize a script into a package with multiple modules.

## Checkpoint
You can: write a small CLI app, structure it as a package, install it in a virtual env, and explain the difference between a list, tuple, and dict to a peer.
