# Module 1.2 — Tooling

**Level:** 1 — Beginner
**Estimated time:** 1 week

## Goal
Set up a productive development environment and learn the everyday tools an AI engineer uses.

## Topics
- VS Code setup: extensions (Python, Pylance, Jupyter), settings, workspaces
- Jupyter notebooks vs `.py` scripts — when to use which
- Git basics: `init`, `add`, `commit`, `branch`, `merge`, `rebase`, `log`
- GitHub: remotes, push/pull, pull requests, issues
- Debugging: VS Code debugger, breakpoints, `pdb`, `breakpoint()`
- Linting & formatting: `ruff`, `black`, `mypy` (intro to type hints)
- Pre-commit hooks
- Reading a stack trace effectively

## Exercises
1. Create a GitHub repo, clone it, push a commit, open a PR against `main` from a feature branch.
2. Set up `ruff` + `black` + `pre-commit` on a small project.
3. Use the VS Code debugger to step through a recursive function.
4. Add type hints to a previous Module 1.1 exercise and run `mypy` on it.

## Resources

- VS Code Python tutorial: https://code.visualstudio.com/docs/python/python-tutorial
- Ruff docs: https://docs.astral.sh/ruff/

## Checkpoint
You can: clone a repo, work on a branch, open a PR, debug breakpoints, and run a linter/formatter on commit.
