# Module 1.3 — Math for AI (Applied)

**Level:** 1 — Beginner
**Estimated time:** 2 weeks

## Goal
Build the math intuition needed to *read* ML papers and tutorials. Not a math degree — just enough to follow along.

## Topics
### Linear algebra
- Scalars, vectors, matrices, tensors
- Dot product, matrix multiplication, transpose, inverse
- Norms (L1, L2), distances, cosine similarity
- Eigenvalues / eigenvectors (intuition only)

### Calculus
- Functions, slopes, derivatives
- Partial derivatives, gradients
- Chain rule (the foundation of backpropagation)

### Probability & Statistics
- Random variables, distributions (normal, Bernoulli, uniform)
- Mean, variance, standard deviation, covariance, correlation
- Conditional probability, Bayes' rule
- Expectation, law of large numbers
- Sampling, central limit theorem

## Exercises
1. Implement vector dot product, matrix multiplication from scratch in Python.
2. Compute cosine similarity between two text-derived vectors.
3. Implement gradient descent for `f(x) = x² + 3x + 2` and plot the path.
4. Simulate 10,000 dice rolls and verify the expected mean.
5. Apply Bayes' rule to a classic medical-test problem.

You can explain — in plain English — what a gradient is, why dot products matter for similarity, and what variance tells you about a dataset.
